# Quickstart: HTML Configuration Options

**Branch**: `019-html-config-options` | **Date**: 2026-06-08

---

## 1. Enabling Interval Gaps
- Load `f1tv_overlay.html` in OBS or a browser.
- Press `Tab` to open the settings panel.
- Check the box labeled **Interval Gaps**.
- The leaderboard timing column will instantly update to show intervals instead of cumulative gaps to the leader.

## 2. Restricting Camera Views and Auto Switching
- Open the control panel `f1tv_control.html` in a web browser.
- Use the **Auto Camera Pool Settings** to select only the desired camera views (e.g. only Chase and TV Cam).
- Toggle the **Disable Auto Cam Switch** checkbox to freeze camera switching entirely while keeping auto driver focus tracking active.
